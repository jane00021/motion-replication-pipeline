# 字幕动效拆解合同

字幕是独立动效组，不是画面动效的附属贴字。每一组都要保存完整文本时钟和可替换参数。

复刻实施前必须读 [校准与返工](replication-calibration.md)。本合同列的是待测字段，不能把填好字段当作完成复刻；先同字静态校准，再逐层真实动作和编码输出对照。重点由语义角色决定，阴影必须在实际应用背景中可见且有证据。不要从烧字成片清理背景后冒充透明可迁移字幕。

## 必须测量

- 原文和语义分段。
- 句、词、字的开始和结束时间。
- 字体文件、字体名、字重、字号、行距、字距、对齐和基线。
- 填充、描边、阴影、底板、遮罩和透明度。
- 主字幕、重点词、数字、标签等文字角色。
- 入场、变色、放大、弹跳、跟随、逐字揭晓、停留和退场。
- 换内容后的换行规则和安全区。
- 逐字核对完整字面。脸两侧各显示一个完整字时，拆成独立字层并给脸留空，不能把整词放在人后再靠遮挡形成两个残字。文字可见性按角色记录 `unoccluded` 或 `intentionally-occluded`，后者须有实际被挡笔画的参考帧。
- 用转折前后相邻帧记录字幕的锚点、行序、颜色和瞬态材质。居中白句向左上让位、转金、次句带竖向拖影入场、双行停留属于不同事件。更换内容时用新词点驱动交接，保持这些事件的先后与空间关系，不能只用双行淡入或更换描边代替。

## 参数结构示例

```json
{
  "id": "SUB-001",
  "source": {"start": 4.2, "end": 7.8},
  "text": "重点内容",
  "segments": [
    {"text": "重点", "role": "emphasis", "start": 4.6, "end": 5.3},
    {"text": "内容", "role": "body", "start": 5.3, "end": 6.2}
  ],
  "style": {"font": "font-file.ttf", "weight": 700, "fill": "#FFFFFF", "stroke": "#111111"},
  "animation": {"entry": "word-reveal", "emphasis": "scale-and-color", "exit": "hold-then-fade"},
  "editable": ["text", "font", "font_size", "emphasis_ranges", "event_time"]
}
```

## 字幕组验收

- 文字不是截图或硬编码旧内容。
- 换内容后每个字都能加载，长短文本不会越界。
- 换字体后重新计算字宽和换行，不沿用旧字体的固定坐标。
- 重点词的揭晓时点与人声和画面一致。
- 字幕出现后有实际阅读时间，动作结束后不立即切走。
