# HTML 展示面板合同

HTML 面板是验收工具，必须能让用户看出每个动效组是什么、何时用、是否能换内容。

面板有两种展示模式。复刻验收模式按完整动效组展示原对标和新口播结果，并在03通过后显示换内容和换字体结果。共享库模式按画面组件、字幕组件和完整组合配方分栏展示，组件使用独立可播放预览，配方显示组件引用、来源、共享时钟、接管和退出。共享库模式的原配方回归视频留在工程验证记录。

拆解阶段的观察页与复刻阶段的预览页必须分开：观察页只能展示参考片段、关键帧、family/occurrence 目录和测量证据，标题必须写“仅拆解，不是复刻”；只有 `03-pilot` 通过后，才允许出现原素材基准、换内容版和换字体版。

## 页面结构

```text
页面标题和项目版本
筛选：画面动效 / 字幕动效 / 开场 / B-roll / 并列 / 强调 / 数据 / 收尾
动效组卡片网格
  - 组编号和功能
  - 来源时间码
  - 原素材基准
  - 换内容版
  - 换字体版
  - 播放与时间轴
  - 编辑参数
  - 已知限制
```

## 每个卡片的最小数据

```json
{
  "id": "SUB-001",
  "kind": "subtitle",
  "category": ["emphasis"],
  "source_time": "00:04.2-00:07.8",
  "baseline": "assets/SUB-001-baseline.mp4",
  "changed_content": "assets/SUB-001-content.mp4",
  "changed_font": "assets/SUB-001-font.mp4",
  "editable": ["text", "font", "event_time"],
  "verified": {"playback": true, "replacement": true, "font_swap": true}
}
```

## 浏览器验收

- 页面首次加载不能有空白卡片或失效媒体。
- 每个视频可播放、暂停、拖动和重新播放。
- 移动端和桌面端均不遮挡文字和控件。
- 卡片不使用“示意图”替代实际渲染视频。
- 换内容和换字体版本必须显示不同结果。
- 页面标注只能说明功能和验证范围，不能把制作说明烧进成片画面。
