# 01、02完整表达与迁移范围

当前为03源码/配方试作；04未激活，不能称正式库。

## 01：劳动情境 → 收入疑问

原完整组cg01 [0,66)帧：用暗角聚焦人物、底部工作图片引入劳动场景，铺垫“为什么／越努力上班”，再由“越存不到钱”与问号接管疑问，画面和字幕共同退出。暗角、图片、字幕不能各自演完就称完整表达。

新片选 [0.000,5.800)秒，涵盖加班、工资扣除生活支出、留不下收入。新字幕“加班／熬到半夜／存不下钱”是语义概括，不声称逐字转录。“存不下钱”为问题结论，白色大字与红色问号突出，不把上一t04的金色词法套用。

替换人物底片、底部工作图片、文字和时长，保留聚焦→工作铺垫→疑问接管→共同退出。图片只用已有本地素材中的无字工作区域，不使用原片清字补丁。文字脚本/声音仍需听审，不能靠ASR宣称原话完全正确。

冲突：下部有关键证据/图表时，图片不能覆盖；边缘内容必须可读时暗角需改聚焦区或禁用。当前圆形聚焦区与下部工作图几何约286×508设计，只验证当前人物位置。疑问结果与铺垫可叠排，但字面不能互相挡读。长字串需缩字或改排，不承诺任意文本。

## 02：风险符号铺垫 → 台词推进 → 背后大标题

原完整组cg02含旧cg03合并：[108,174)帧。批量金币进入前景、下落、翻转与近大远小模糊；普通口播字幕推进；大标题“财富真相”在上方撑满，位于人物头部后；金币让位后标题保持。配方不能缺失标题/头部遮挡，不能以小贴字替代背后巨字。

新片选 [29.300,32.100)秒，台词提醒不要相信短期快速赚钱。“金币”只承担原内容中的财富符号，可替换成风险警示图标；新标题“警惕快钱”承担结论。不是单独撒图标，而是图标运动铺垫→句子推进→后置巨字接管→图标退出/标题保持。

替换人物、符号图像、字幕、标题和时长。符号是可换PNG/WebP输入，运动组件仍控制数量、尺寸、速度、翻转、旋转、近远模糊；字号/材质归字幕组件，人物抠像归画面组件，配方控制二者前后关系。

冲突：标题后置需要新人物头部alpha，当前固定种子GrabCut只验证此片近似正中人物，不承诺任意人物/手势/镜头位置。无合格遮罩时必须拒绝声称完成后置标题；不能悄悄改为前景字。符号过密、过大或在光峰值遮住面部/标题时须降密度/挪轨迹。新语义若不是风险，警示图标不适用，需换素材与结论。
